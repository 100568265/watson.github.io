# 左值&右值(lvalue & rvalue)

## 左值和右值有什么区别？

- **能取地址、有名字、能反复使用的 = 左值**
- **不能取地址、没名字、临时用完就销毁的 = 右值**



## C++标准定义

### 左值(lvalue)

有标识符(名字)

内存中有稳定位置

可以赋值，取地址

生命周期长(变量，对象，数组等)



**常见左值**：

普通变量 `int x;`

引用 `int& r = x;`

函数名

字符串常量 `"hello"`



### 右值(rvalue)

**没有名字**（临时值）

内存位置不稳定，**用完立即销毁**

**不能取地址**、不能赋值

生命周期极短



**常见右值**：

字面常量 `10`, `3.14`, `true`

表达式运算结果 `a+b`, `x*y`

函数返回的**临时对象**

临时创建的对象 `MyClass()`



## 关键规则

1. 左值引用 `int&` 只能绑定左值

```cpp
int a = 10;
int& r1 = a;   // ✅ 合法
int& r2 = 10;  // ❌ 错误！10 是右值
```



2. const 左值引用 `const int&` 可以绑定任何值

```cpp
const int& r = 10;  // ✅ 合法
```



3. 右值引用 `int&&` 只能绑定右值

```cpp
int&& r1 = 10;    // ✅ 合法
int a = 10;
int&& r2 = a;     // ❌ 错误！a 是左值
```
